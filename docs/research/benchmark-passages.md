# Benchmark passages (ground truth)

Read each one as written, at your normal pace, as if you were dictating it. Say punctuation
only where you normally would (most people don't). One recording per passage.

p02. Thanks, that works for me. Let's catch up on Friday afternoon.

p03. I'm running about ten minutes late, start without me and I'll join as soon as I can.

p04. Vocette is a dictation app for Windows that types what you say into any program.

p05. Hi Sarah, following up on our call last week. I've attached the revised budget, which comes to four thousand two hundred and fifty dollars, and moved the deadline to the twenty-third of November. Let me know if anything needs changing.

p06. The bug only happens when the window is minimised, so I think the Electron main process is losing the focus event.

p07. Please book a table for six people at seven thirty on Saturday, and ask if they have anything vegetarian.

p11. Honestly, I wasn't sure it would work, but after a week of using it every day I can't go back to typing.

p13. Remind me to call the dentist on Monday morning.
